**Q:** 9.11 和 9.8 哪个大？

**A:** 在数学上，"9.11" 和 "9.8" 是两个不同的数值。它们代表的是同一个数字，只是在不同的格式下表示。

- "9.11" 表示十进制数 911。
- "9.8" 表示十进制数 98。

因此，这两个数字是相等的。

**Q:** 写一个 Python 函数计算两数之和。

**A:** 当然可以，下面是一个简单的Python函数，用于计算两个数的和：

```python
def add_numbers(a, b):
    return a + b

# 示例使用
result = add_numbers(3, 5)
print(result)  # 输出: 8
```
